# Changelog

## 0.1.0 — 2026-09-19

First public release of the interactive demo for csm-rs.

- Local Rust server with a browser UI and included frontend assets.
- Generated scan scenarios and import of ordered polar or Cartesian scan pairs.
- Interactive initial-pose placement, explicit matching, and iteration inspection.
- Matching outcomes, ground-truth errors for generated scans, and drift metrics.
- Named experiment storage and replay with scan, configuration, and version data.
